# Чат-бот MAX: создание и подключение

Для управления заказами из мессенджера MAX нужен чат-бот с токеном.
Создавать бота может только верифицированный профиль бизнеса
(юрлицо, ИП или самозанятый — резидент РФ).

## 1. Создание бота

1. Откройте платформу для бизнеса: <https://business.max.ru/self>
2. Раздел **Чат-боты** → **Создать бота**.
3. Укажите имя бота (например, «Студия 3D»), загрузите аватар при желании.
4. После создания бот появится в списке чат-ботов.

## 2. Получение токена

1. В списке чат-ботов нажмите **Перейти** у вашего бота.
2. **Расширенные настройки** → **Настроить**.
3. Скопируйте **токен доступа** (access token).

> Если бот создан в мини-приложении «MAX для бизнеса» или в боте
> «MAX для бизнеса» (команда **Получить токен**) — токен можно взять там же.
>
> Токен секретный: не публикуйте его, не коммитьте в git.

## 3. Подключение к приложению

Заполните в `.env` (скопируйте из `.env.example`):

```dotenv
MAX_TOKEN=<токен из шага 2>
MAX_ENDPOINT=https://platform-api2.max.ru
MAX_ADMIN_ID=<user_id оператора>
```

### Как узнать свой user_id

Отправьте боту в MAX любое сообщение (например, `привет`), затем посмотрите
лог бота:

```bash
journalctl -u orders-max-bot -f
```

В логе появится событие `message_created` с полем `user.id` — это и есть
ваш `user_id`. Впишите его в `MAX_ADMIN_ID`.

## 4. Запуск

Локально:

```bash
python max_bot.py
```

На Orange Pi сервис запускается автоматически:

```bash
sudo systemctl restart orders-max-bot
journalctl -u orders-max-bot -f
```

## 5. Команды оператора

| Команда                | Что делает                                  |
|------------------------|---------------------------------------------|
| `/help`                | Список команд                               |
| `/orders`              | Список заказов (кнопки для деталей)         |
| `/order <номер>`       | Детали заказа + кнопки смены статуса        |
| `/status <номер>`      | Кнопки смены статуса                        |
| `/status <номер> <ст>` | Смена статуса текстом, напр. `/status 3 готов` |
| `/clients`             | Список клиентов                             |

Смена статуса через бота автоматически уведомляет клиента во все
включённые каналы (Telegram / VK / MAX).

## Примечания

- Бот работает в режиме **Long Polling** (`GET /updates`) — публичный
  HTTPS-адрес не нужен, подходит для локальной сети.
- Для больших нагрузок MAX рекомендует **Webhook** (`POST /subscriptions`),
  но он требует публичного HTTPS-адреса с доверенным сертификатом
  (включая сертификаты Минцифры). Для студии на Orange Pi достаточно
  Long Polling.
- Лимит отправки: не более 2 сообщений в секунду в один диалог.
