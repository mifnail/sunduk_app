# Заказы — система управления заказами студии 3D-печати и 3D-сканирования

Простое и эффективное приложение для управления заказами:
- база клиентов;
- заказы с привязкой к услугам и статусами;
- история смены статусов;
- автоуведомления клиентов при смене статуса (Telegram / VK / MAX);
- чат-бот MAX для оператора (список заказов, смена статуса, клиенты).

## Стек
- Python 3, Flask
- SQLite (нормализация до 3НФ)
- Серверные шаблоны Jinja2, минимум JS
- pytest
- Деплой: Orange Pi (Linux/ARM64), systemd

## Структура
```
app.py            — Flask-приложение (роуты)
database.py       — вся SQL-логика
db_schema.py      — схема БД и инициализация
notifier.py       — отправка уведомлений
max_bot.py        — чат-бот MAX для оператора (Long Polling)
templates/        — шаблоны UI
static/           — CSS/JS
tests/            — pytest-тесты
```

## Запуск (локально)
```bash
pip install -r requirements.txt
python app.py
```
Открыть http://127.0.0.1:5000

## Уведомления
Каналы настраиваются в `.env` (см. `.env.example`):
- **Telegram** — `TG_TOKEN` (токен бота от @BotFather)
- **VK** — `VK_TOKEN` + `VK_GROUP_ID` (токен сообщества VK Bot API, метод `messages.send`)
- **MAX** — `MAX_TOKEN` (токен чат-бота: `business.max.ru/self` → Чат-боты → Настроить) + `MAX_ENDPOINT` (по умолчанию `https://platform-api2.max.ru`)

У клиента включите нужные каналы и укажите идентификаторы (telegram_id / vk_id / max_id).
При смене статуса заказа клиент получает уведомление во все включённые каналы.
Отказ одного канала не влияет на остальные.

## Чат-бот MAX (оператор)
`max_bot.py` — бот для оператора в мессенджере MAX, работает через Long Polling
(без публичного HTTPS-адреса). Укажите `MAX_TOKEN` и `MAX_ADMIN_ID` (user_id
операторов через запятую). Запуск: `python max_bot.py`. Команды:
- `/orders` — список заказов с кнопками
- `/order <номер>` — детали заказа
- `/status <номер> [статус]` — смена статуса (кнопки или текстом)
- `/clients` — список клиентов
- `/help` — помощь

Смена статуса через бота уведомляет клиента во все включённые каналы
(та же логика, что и в веб-интерфейсе). Как создать бота MAX — в `docs/max_bot.md`.

## Деплой на Orange Pi
1. Скопируйте проект в `/opt/orders_app` на одноплатнике.
2. Заполните `/opt/orders_app/.env` ключами.
3. Запустите `sudo bash deploy/install.sh`.
4. Сервисы `orders` (веб) и `orders-max-bot` (бот MAX) будут автоматически запускаться при загрузке.
5. Проверка: `systemctl status orders orders-max-bot`, откройте `http://<IP>:5000`.
